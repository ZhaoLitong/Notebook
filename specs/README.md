# Notebook Specifications

This directory contains the initial specifications for a general-purpose notebook with meeting minutes as a secondary workflow.

- [Product specification](./product-spec.md): product goals, scope, workflows, requirements, and acceptance criteria.
- [Technical specification](./technical-spec.md): architecture, data model, synchronization, voice input, security, and delivery plan.

These documents describe an initial single-user-friendly MVP that can evolve into a multi-user product. Decisions that are intentionally deferred are listed in the roadmap rather than treated as hidden requirements.
