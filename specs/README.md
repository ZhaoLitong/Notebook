# Notebook Specifications

This directory contains the initial specifications for a general-purpose notebook with meeting minutes as a secondary workflow.

- [Product specification](./product-spec.md): product goals, scope, workflows, requirements, and acceptance criteria.
- [Technical specification](./technical-spec.md): architecture, data model, synchronization, voice input, security, and delivery plan.

These documents describe the intended single-user-friendly product and a path to a multi-user product. The product specification includes the current scaffold boundary so planned requirements are not confused with implemented behavior. The technical specification documents the framework-free modular MVP architecture and distinguishes it from later hosted architecture. Decisions that are intentionally deferred are listed in the roadmap rather than treated as hidden requirements.
